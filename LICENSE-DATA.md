- `dist/lessons/` — exported lesson packets

`dist/schema/` JSON schema — the schema is an interface contract, not generated
data.

The shipped lessons were produced with LLM-assisted authoring and reviewed through
the human and automated workflow in this repository. Exported packets do not carry
