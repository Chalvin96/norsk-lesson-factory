## A weekend at the cabin {#weekend-at-the-cabin role=orient objectives=obj-conditional-clauses-01}

Maja and Jonas are planning a weekend at Jonas’s family cabin. The weather forecast is uncertain, and the cabin is fairly simple.

::: {.reading translation="Are we going to the cabin on Saturday?" dialogue_id=cabin-planning speaker_id=maja speaker_name="Maja" character_id="maja"}
Skal vi dra på hytta på lørdag?
:::

::: {.reading translation="Yes. If it doesn’t rain, we’ll go for a long walk." dialogue_id=cabin-planning speaker_id=jonas speaker_name="Jonas" character_id="jonas"}
Ja. Hvis det ikke regner, går vi en lang tur.
:::

::: {.reading translation="And if it rains?" dialogue_id=cabin-planning speaker_id=maja speaker_name="Maja" character_id="maja"}
Og hvis det regner?
:::

::: {.reading translation="Then we’ll stay inside and make dinner." dialogue_id=cabin-planning speaker_id=jonas speaker_name="Jonas" character_id="jonas"}
Da blir vi inne og lager middag.
:::

::: {.reading translation="If the cabin had internet, I would bring my computer." dialogue_id=cabin-planning speaker_id=maja speaker_name="Maja" character_id="maja"}
Hvis hytta hadde internett, ville jeg tatt med datamaskinen.
:::

::: {.reading translation="If I were you, I would leave it at home." dialogue_id=cabin-planning speaker_id=jonas speaker_name="Jonas" character_id="jonas"}
Hvis jeg var deg, ville jeg latt den ligge hjemme.
:::

::: {.reading translation="Maybe you’re right. But if you don’t bring coffee, I’m staying home." dialogue_id=cabin-planning speaker_id=maja speaker_name="Maja" character_id="maja"}
Kanskje du har rett. Men hvis du ikke tar med kaffe, blir jeg hjemme.
:::

::: {.reading translation="All right. If you buy coffee, I’ll bring something nice for breakfast." dialogue_id=cabin-planning speaker_id=jonas speaker_name="Jonas" character_id="jonas"}
Greit. Hvis du kjøper kaffe, tar jeg med noe godt til frokosten.
:::

Maja and Jonas use *hvis*—“if”—to connect a condition with its result. Some of their conditions are realistic possibilities: it may rain, and someone must buy coffee. Others are imagined situations: the cabin does not have internet, but Maja imagines what she would do if it did.

The main challenge is not simply remembering *hvis*. You need to choose between a real condition and an imagined condition, and you need the correct word order both inside the *hvis*-clause and in the clause that follows it.

## Real conditions {#real-conditions role=model objectives=obj-conditional-clauses-01}

A real condition presents something as possible, expected, or relevant to an actual decision.

::: examples
- no: Hvis det ikke regner, går vi en lang tur.
- en: If it doesn’t rain, we’ll go for a long walk.
:::

The speaker does not know whether it will rain. Both outcomes are still possible.

A clause introduced by *hvis* is a subordinate clause (*leddsetning*). In a subordinate clause, a sentence adverb such as *ikke* normally comes before the finite verb:

::: examples
- no: hvis det ikke regner
- en: if it does not rain
:::

Compare the order:

**Main clause and *hvis*-clause**

::: examples
- no: Det regner ikke.
- en: It isn’t raining.
- no: hvis det ikke regner
- en: if it isn’t raining
- no: Du tar ikke med kaffe.
- en: You aren’t bringing coffee.
- no: hvis du ikke tar med kaffe
- en: if you don’t bring coffee
- no: Bussen kommer ikke.
- en: The bus isn’t coming.
- no: hvis bussen ikke kommer
- en: if the bus doesn’t come
:::

The compact rule is:

::: {.rule}
In a *hvis*-clause, place *ikke* before the finite verb.
:::

This follows the subordinate-clause word order that you already know. The word *hvis* does not change the rule.

**Notice the result clause**

When the *hvis*-clause comes first, it occupies the first position in the complete sentence. The following main clause therefore begins with its finite verb:

::: examples
- no: Hvis det ikke regner, går vi en lang tur.
- en: If it doesn’t rain, we’ll go for a long walk.
:::

The main clause is *vi går en lang tur*. After the initial *hvis*-clause, the order becomes *går vi*.

More examples:

::: examples
- no: Hvis butikken er åpen, kjøper jeg kaffe.
- en: If the shop is open, I’ll buy coffee.
- no: Hvis toget kommer i tide, rekker vi møtet.
- en: If the train arrives on time, we’ll make the meeting.
- no: Hvis Nora ikke svarer, sender jeg henne en melding.
- en: If Nora doesn’t answer, I’ll send her a message.
- no: Hvis dere er sultne, kan vi spise nå.
- en: If you are hungry, we can eat now.
:::

Notice that the finite verb comes before the subject in each result clause: *kjøper jeg*, *rekker vi*, *sender jeg* and *kan vi*.

The compact pattern is:

::: {.rule}
**Hvis + subordinate clause, finite verb + subject in the main clause.**
:::

A common mistake is to keep ordinary subject–verb order after an initial *hvis*-clause:

::: examples
- no: ✗ Hvis butikken er åpen, jeg kjøper kaffe.
- en: Intended meaning: If the shop is open, I’ll buy coffee.
:::

The correct sentence is:

::: examples
- no: Hvis butikken er åpen, kjøper jeg kaffe.
- en: If the shop is open, I’ll buy coffee.
:::

The comma does not create the inversion. The inversion happens because the complete *hvis*-clause fills the first position before the main-clause verb.

## Putting the condition second {#putting-condition-second role=contrast objectives=obj-conditional-clauses-01}

The condition can also follow the result:

::: examples
- no: Vi går en lang tur hvis det ikke regner.
- en: We’ll go for a long walk if it doesn’t rain.
- no: Jeg kjøper kaffe hvis butikken er åpen.
- en: I’ll buy coffee if the shop is open.
- no: Jeg sender Nora en melding hvis hun ikke svarer.
- en: I’ll send Nora a message if she doesn’t answer.
:::

Here the main clause comes first, so it keeps ordinary main-clause order:

::: examples
- no: Vi går en lang tur …
- en: We’ll go for a long walk …
:::

The *hvis*-clause remains a subordinate clause even when it comes second. Its internal word order does not change:

::: examples
- no: … hvis det ikke regner
- en: … if it doesn’t rain
:::

Compare the two arrangements:

::: examples
- no: Hvis bussen ikke kommer, tar vi taxi.
- en: If the bus doesn’t come, we’ll take a taxi.
- no: Vi tar taxi hvis bussen ikke kommer.
- en: We’ll take a taxi if the bus doesn’t come.
:::

The condition and result are essentially the same. What changes is which part the speaker presents first. In the first sentence, the condition is the starting point. In the second, the decision is stated first and then limited by the condition.

Do not move *ikke* after the verb merely because the *hvis*-clause comes at the end:

::: examples
- no: ✗ Vi tar taxi hvis bussen kommer ikke.
- en: Intended meaning: We’ll take a taxi if the bus doesn’t come.
:::

Use subordinate-clause order:

::: examples
- no: Vi tar taxi hvis bussen ikke kommer.
- en: We’ll take a taxi if the bus doesn’t come.
:::

## What real conditions can express {#real-condition-uses role=model objectives=obj-conditional-clauses-01}

Real conditions are not limited to future plans. They can describe repeated results, practical instructions, or consequences that the speaker sees as genuine possibilities.

**A repeated or usual result**

::: examples
- no: Hvis Jonas lager middag, vasker Maja opp.
- en: If Jonas makes dinner, Maja does the washing-up.
- no: Hvis jeg jobber sent, tar jeg bussen hjem.
- en: If I work late, I take the bus home.
:::

**A practical instruction**

::: examples
- no: Hvis døra er låst, ringer du på.
- en: If the door is locked, ring the bell.
- no: Hvis du ikke finner hytta, kan du ringe meg.
- en: If you can’t find the cabin, you can call me.
:::

**A possible consequence**

::: examples
- no: Hvis vi drar tidlig, får vi god tid.
- en: If we leave early, we’ll have plenty of time.
- no: Hvis du ikke bestiller i dag, blir billettene dyrere.
- en: If you don’t book today, the tickets will become more expensive.
:::

English often uses “will” in the result when talking about the future. Norwegian frequently uses the present tense when the future meaning is clear from the situation:

::: examples
- no: Hvis været blir bedre, går vi ut.
- en: If the weather improves, we’ll go outside.
:::

A modal verb can also express the result:

::: examples
- no: Hvis været blir bedre, kan vi gå ut.
- en: If the weather improves, we can go outside.
- no: Hvis været blir bedre, skal vi gå ut.
- en: If the weather improves, we’ll go outside.
:::

The central choice remains the same: the speaker treats the condition as a real possibility.

## Imagined conditions {#imagined-conditions role=contrast objectives=obj-conditional-clauses-01}

Maja also says:

::: examples
- no: Hvis hytta hadde internett, ville jeg tatt med datamaskinen.
- en: If the cabin had internet, I would bring my computer.
:::

The cabin does not have internet, or Maja at least treats internet there as unlikely. She imagines a different situation and its result.

For this kind of imagined condition, Norwegian commonly uses the past tense (*preteritum*) in the *hvis*-clause and *ville* plus an infinitive in the result clause:

::: examples
- no: Hvis hytta hadde internett, ville jeg tatt med datamaskinen.
- en: If the cabin had internet, I would bring my computer.
:::

The form *hadde* is past tense, but the sentence is not necessarily about past time. It presents the condition as imagined or remote from the current situation.

Compare:

::: examples
- no: Hvis hytta har internett, tar jeg med datamaskinen.
- en: If the cabin has internet, I’ll bring my computer.
- no: Hvis hytta hadde internett, ville jeg tatt med datamaskinen.
- en: If the cabin had internet, I would bring my computer.
:::

In the first sentence, Maja treats internet access as a real possibility to check. In the second, she imagines a different situation.

Another pair:

::: examples
- no: Hvis jeg har tid, hjelper jeg deg.
- en: If I have time, I’ll help you.
- no: Hvis jeg hadde tid, ville jeg hjulpet deg.
- en: If I had time, I would help you.
:::

The second sentence often suggests that the speaker does not currently have enough time.

A third pair:

::: examples
- no: Hvis vi bor nærmere, besøker vi dem oftere.
- en: If we live closer, we visit them more often.
- no: Hvis vi bodde nærmere, ville vi besøkt dem oftere.
- en: If we lived closer, we would visit them more often.
:::

The compact imagined-condition pattern is:

::: {.rule}
**Hvis + past tense, ville + infinitive or past participle form used with *ville*.**
:::

Common Bokmål examples include *ville hjelpe* and *ville hjulpet*. Both patterns occur naturally. In this chapter, focus on recognizing and producing the established combinations presented in the examples, without treating the imagined past-tense form as ordinary past time.

**Hvis jeg var deg**

Jonas gives Maja advice:

::: examples
- no: Hvis jeg var deg, ville jeg latt datamaskinen ligge hjemme.
- en: If I were you, I would leave the computer at home.
:::

*Hvis jeg var deg* is a common way to introduce advice. The speaker cannot literally become the other person, so the condition is imagined.

More examples:

::: examples
- no: Hvis jeg var deg, ville jeg bestilt billettene i dag.
- en: If I were you, I would book the tickets today.
- no: Hvis jeg var deg, ville jeg ikke ventet så lenge.
- en: If I were you, I wouldn’t wait so long.
- no: Hvis jeg var deg, ville jeg tatt med en varm jakke.
- en: If I were you, I would bring a warm jacket.
:::

Inside *hvis jeg var deg*, the order is subordinate-clause order. In the following main clause, *ville* comes before the subject because the *hvis*-clause comes first:

::: examples
- no: ville jeg
- en: would I
:::

If the result comes first, ordinary main-clause order returns:

::: examples
- no: Jeg ville tatt med en varm jakke hvis jeg var deg.
- en: I would bring a warm jacket if I were you.
:::

## Word order in imagined conditions {#imagined-condition-word-order role=contrast objectives=obj-conditional-clauses-01}

Imagined conditions follow the same word-order rules as real conditions. The difference lies in the verb forms, not in a new clause structure.

**Negation inside the *hvis*-clause**

::: examples
- no: Hvis hytta ikke hadde strøm, ville vi brukt stearinlys.
- en: If the cabin didn’t have electricity, we would use candles.
- no: Hvis jeg ikke bodde så langt unna, ville jeg kommet oftere.
- en: If I didn’t live so far away, I would come more often.
:::

In each *hvis*-clause, *ikke* comes before the finite verb:

- **ikke hadde** — *didn’t have*
- **ikke bodde** — *didn’t live*

**Negation in the result clause**

::: examples
- no: Hvis hytta lå nærmere byen, ville vi ikke trengt bil.
- en: If the cabin were closer to town, we wouldn’t need a car.
:::

The result is a main clause. Here *ikke* follows the finite verb *ville*:

::: examples
- no: ville vi ikke trengt
- en: we would not need
:::

Compare the two positions:

::: examples
- no: Hvis vi ikke hadde bil, ville vi tatt bussen.
- en: If we didn’t have a car, we would take the bus.
- no: Hvis vi hadde bil, ville vi ikke tatt bussen.
- en: If we had a car, we wouldn’t take the bus.
:::

In the first sentence, the condition is negative: *if we didn’t have a car*. In the second, the imagined result is negative: *we wouldn’t take the bus*.

This contrast matters because the position of *ikke* changes what is being denied.

**A likely misconception**

Do not place *ikke* after the finite verb inside an imagined *hvis*-clause:

::: examples
- no: ✗ Hvis vi hadde ikke bil, ville vi tatt bussen.
- en: Intended meaning: If we didn’t have a car, we would take the bus.
:::

Use:

::: examples
- no: Hvis vi ikke hadde bil, ville vi tatt bussen.
- en: If we didn’t have a car, we would take the bus.
:::

Also remember inversion after an initial condition:

::: examples
- no: ✗ Hvis vi ikke hadde bil, vi ville tatt bussen.
- en: Intended meaning: If we didn’t have a car, we would take the bus.
:::

Use:

::: examples
- no: Hvis vi ikke hadde bil, ville vi tatt bussen.
- en: If we didn’t have a car, we would take the bus.
:::

## Back at the cabin plan {#back-at-the-cabin-plan role=model objectives=obj-conditional-clauses-01}

Jonas checks the forecast again on Friday evening.

::: {.reading translation="Apparently it’s going to rain in the morning." dialogue_id=updated-cabin-plan speaker_id=jonas speaker_name="Jonas" character_id="jonas"}
Det skal visst regne om morgenen.
:::

::: {.reading translation="If it stops raining before lunch, we’ll go for a walk afterwards." dialogue_id=updated-cabin-plan speaker_id=maja speaker_name="Maja" character_id="maja"}
Hvis det slutter å regne før lunsj, går vi tur etterpå.
:::

::: {.reading translation="Good idea. If we don’t make it to the shop tonight, we can shop on the way tomorrow." dialogue_id=updated-cabin-plan speaker_id=jonas speaker_name="Jonas" character_id="jonas"}
God idé. Hvis vi ikke rekker butikken i kveld, kan vi handle på veien i morgen.
:::

::: {.reading translation="If the cabin were closer, we wouldn’t need to plan so much." dialogue_id=updated-cabin-plan speaker_id=maja speaker_name="Maja" character_id="maja"}
Hvis hytta lå nærmere, ville vi ikke trengt å planlegge så mye.
:::

::: {.reading translation="That’s true. But I wouldn’t like it as much if it were in the middle of town." dialogue_id=updated-cabin-plan speaker_id=jonas speaker_name="Jonas" character_id="jonas"}
Det er sant. Men jeg ville ikke likt den like godt hvis den lå midt i byen.
:::

The same two meaning choices now help them respond to new information.

Their first two conditions are real:

::: examples
- no: Hvis det slutter å regne før lunsj, går vi tur etterpå.
- en: If it stops raining before lunch, we’ll go for a walk afterwards.
- no: Hvis vi ikke rekker butikken i kveld, kan vi handle på veien i morgen.
- en: If we don’t make it to the shop tonight, we can shop on the way tomorrow.
:::

They are practical possibilities that may affect the plan.

The next two conditions are imagined:

::: examples
- no: Hvis hytta lå nærmere, ville vi ikke trengt å planlegge så mye.
- en: If the cabin were closer, we wouldn’t need to plan so much.
- no: Jeg ville ikke likt den like godt hvis den lå midt i byen.
- en: I wouldn’t like it as much if it were in the middle of town.
:::

The cabin is not closer and is not in the middle of town. Jonas and Maja use past-tense forms in the conditions—*lå*—and *ville* in the results to imagine alternatives.

Notice the word order in the final sentence. Because the result comes first, it begins with normal main-clause order:

::: examples
- no: Jeg ville ikke likt …
- en: I wouldn’t like …
:::

The final *hvis*-clause keeps subordinate-clause order:

::: examples
- no: hvis den lå midt i byen
- en: if it were in the middle of town
:::
