# Catalog registries

This directory contains active YAML registries used by catalog planning and
family routing.

- `catalog_families.yaml` is the controlled family and catalog-kind registry.

These files are authoring inputs. `catalog/approved/catalog.yaml` is the
approved owner catalog, and JSON remains a derived export format only.

An old grammar-only registry may be kept locally at
`store/archive/catalog/grammar_families.yaml`; that path is ignored and is not
part of the active catalog.
