## An evening at the community center {#evening-community-center role=orient objectives=obj-reciprocal-pronouns-01}

Mina and Jonas help organize activities at a neighborhood community center. This evening, several volunteers are preparing a room for a language café.

::: {.reading translation="Should we move the tables separately?" dialogue_id="community-center-opening" speaker_id="mina" speaker_name="Mina" character_id="mina"}

:::

::: {.reading translation="No, we can help each other." dialogue_id="community-center-opening" speaker_id="jonas" speaker_name="Jonas" character_id="jonas"}

:::

::: {.reading translation="Good idea. Sara and Emil are talking to each other about the food." dialogue_id="community-center-opening" speaker_id="mina" speaker_name="Mina" character_id="mina"}
God idé. Sara og Emil snakker med hverandre om maten.
:::

::: {.reading translation="Yes, and the new volunteers do not know each other yet." dialogue_id="community-center-opening" speaker_id="jonas" speaker_name="Jonas" character_id="jonas"}
Ja, og de nye frivillige kjenner ikke hverandre ennå.
:::

::: {.reading translation="Then we can introduce them to each other." dialogue_id="community-center-opening" speaker_id="mina" speaker_name="Mina" character_id="mina"}
Da kan vi presentere dem for hverandre.
:::

::: {.reading translation="Perfect. Afterwards, we’ll send each other a message about next week." dialogue_id="community-center-opening" speaker_id="jonas" speaker_name="Jonas" character_id="jonas"}

:::

Everyone in the scene is doing something in relation to someone else. Mina helps Jonas, and Jonas helps Mina. Sara speaks to Emil, and Emil speaks to Sara. This shared, two-way relationship is expressed with **hverandre**, meaning **each other** or **one another**.

## Seeing the shared action {#seeing-shared-action role=model objectives=obj-reciprocal-pronouns-01}

Use **hverandre** when two or more people perform an action that connects them reciprocally. A reciprocal action goes in both or several directions.

::: examples
- no: Mina og Jonas hjelper hverandre.
- en: Mina and Jonas help each other.
:::

This means Mina helps Jonas and Jonas helps Mina.

::: examples
- no: Sara og Emil snakker med hverandre.
- en: Sara and Emil talk to each other.
:::

Sara talks to Emil, and Emil talks to Sara.

The people involved normally appear together as the subject:

::: examples
- no: Vi forstår hverandre.
- en: We understand each other.
- no: De kjenner hverandre godt.
- en: They know each other well.
- no: Læreren og studenten respekterer hverandre.
- en: The teacher and the student respect each other.
:::

The subject may be a plural pronoun such as **vi** or **de**, or it may name two or more people.

**Compact rule**

Use **hverandre** when two or more participants do something to, for, with, or in relation to one another.

**Hverandre** does not change for gender or number:

::: examples
- no: De to søstrene ringer hverandre hver søndag.
- en: The two sisters call each other every Sunday.
- no: De tre naboene hjelper hverandre om vinteren.
- en: The three neighbors help one another in winter.
- no: Vi møter hverandre ofte på bussen.
- en: We often meet each other on the bus.
:::

## Hverandre as the object of a verb {#hverandre-direct-object role=model objectives=obj-reciprocal-pronouns-01}

Many verbs can take **hverandre** directly as their object. In these examples, no preposition is needed.

::: examples
- no: Vi hjelper hverandre.
- en: We help each other.
- no: De kjenner hverandre.
- en: They know each other.
- no: Barna følger hverandre hjem.
- en: The children walk each other home.
- no: Kollegene støtter hverandre.
- en: The colleagues support each other.
- no: Mina og Jonas møter hverandre ved inngangen.
- en: Mina and Jonas meet each other at the entrance.
:::

Compare a sentence with a single-direction object:

::: examples
- no: Mina hjelper Jonas.
- en: Mina helps Jonas.
:::

Only Mina is presented as the helper. Jonas receives the help.

Now compare the reciprocal sentence:

::: examples
- no: Mina og Jonas hjelper hverandre.
- en: Mina and Jonas help each other.
:::

Here the help goes both ways.

The same contrast appears with pronouns:

::: examples
- no: De hjelper dem.
- en: They help them.
- no: De hjelper hverandre.
- en: They help each other.
:::

In the first sentence, **de** and **dem** may refer to two different groups. In the second, the members of the subject group help one another.

**Common mistake: using an ordinary object pronoun**

An English speaker may try to translate **each other** with a plural object pronoun:

::: examples
- no: Vi ser oss selv i speilet.
- en: 'Not: We see ourselves in the mirror. (for the reciprocal meaning)'
:::

This has a reflexive meaning: we see ourselves. It does not express **we see each other**. Use **hverandre** for the reciprocal meaning:

::: examples
- no: Vi ser hverandre hver morgen.
- en: We see each other every morning.
:::

Likewise:

::: examples
- no: De besøker dem ofte.
- en: They visit them often.
:::

This means one group visits another group. It does not say that the members visit one another.

::: examples
- no: De besøker hverandre ofte.
- en: They visit each other often.
:::

This clearly gives the reciprocal meaning.

## Hverandre after a preposition {#hverandre-after-preposition role=model objectives=obj-reciprocal-pronouns-01}

Some actions connect people through a preposition. Norwegian keeps the preposition before **hverandre**.

In the opening dialogue, Sara and Emil were discussing the food:

::: examples
- no: Sara og Emil snakker med hverandre.
- en: Sara and Emil talk to each other.
:::

The verb expression is **snakke med**, so the reciprocal expression is **med hverandre**.

::: examples
- no: Vi lærer av hverandre.
- en: We learn from each other.
- no: De passer på hverandre.
- en: They look after each other.
- no: Naboene deler verktøy med hverandre.
- en: The neighbors share tools with each other.
- no: Studentene øver med hverandre.
- en: The students practice with each other.
- no: Mina og Jonas venter på hverandre utenfor.
- en: Mina and Jonas wait for each other outside.
:::

The relevant preposition comes from the Norwegian expression:

- **snakke med** becomes **snakke med hverandre**
- **lære av** becomes **lære av hverandre**
- **vente på** becomes **vente på hverandre**
- **passe på** becomes **passe på hverandre**

Do not automatically copy the English preposition. Use the preposition required by the Norwegian verb or expression.

Compare:

::: examples
- no: De snakker om hverandre.
- en: They talk about each other.
- no: De snakker med hverandre.
- en: They talk to each other.
:::

Both sentences contain **hverandre**, but the preposition changes the relationship. In the first, the people are the topic of conversation. In the second, they are conversation partners.

The central grammar point remains the same: **hverandre** identifies the people as reciprocally connected. The preposition tells us what kind of connection the verb requires.

## One direction or both directions? {#one-direction-or-both-directions role=contrast objectives=obj-reciprocal-pronouns-01}

The most important choice is not grammatical shape but meaning. Ask whether the action is presented as mutual.

::: examples
- no: Jonas sender Mina en melding.
- en: Jonas sends Mina a message.
:::

This describes one message from Jonas to Mina.

::: examples
- no: Jonas og Mina sender hverandre meldinger.
- en: Jonas and Mina send each other messages.
:::

This describes messages moving between them.

::: examples
- no: Sara presenterer Emil for de nye frivillige.
- en: Sara introduces Emil to the new volunteers.
:::

Sara performs the introduction.

::: examples
- no: Sara presenterer de nye frivillige for hverandre.
- en: Sara introduces the new volunteers to each other.
:::

Sara causes the new volunteers to become acquainted with one another.

A plural subject alone does not guarantee a reciprocal meaning:

::: examples
- no: Mina og Jonas åpner døra.
- en: Mina and Jonas open the door.
:::

They may perform the same action together, but they do not open one another. There is no reciprocal relationship.

::: examples
- no: Mina og Jonas ser på hverandre.
- en: Mina and Jonas look at each other.
:::

Here each person looks at the other, so **hverandre** is appropriate.

**Common mistake: treating every shared activity as reciprocal**

People can do the same activity together without acting toward one another.

::: examples
- no: Vi lager middag sammen.
- en: We make dinner together.
- no: Vi lager middag til hverandre.
- en: We make dinner for each other.
:::

This describes cooperation in one activity.

This says that each person makes food for the other.

::: examples
- no: De går sammen til jobben.
- en: They walk to work together.
- no: De venter på hverandre før de går til jobben.
- en: They wait for each other before walking to work.
:::

Use **hverandre** only when the action connects the participants in the intended reciprocal relationship.

## More than two people {#more-than-two-people role=model objectives=obj-reciprocal-pronouns-01}

English often uses **each other** for two people and sometimes **one another** for a larger group. Norwegian normally uses **hverandre** in both cases.

::: examples
- no: De to vennene stoler på hverandre.
- en: The two friends trust each other.
- no: Alle i gruppa lytter til hverandre.
- en: Everyone in the group listens to one another.
- no: Spillerne oppmuntrer hverandre før kampen.
- en: The players encourage one another before the match.
- no: Vi sender hverandre bilder fra turen.
- en: We send one another pictures from the trip.
:::

With a larger group, the exact pattern of individual actions may depend on context. The sentence presents the group members as mutually connected; it does not always claim that every person performs the action separately toward every other person.

## Building useful sentences {#building-useful-sentences role=model objectives=obj-reciprocal-pronouns-01}

A practical way to form a reciprocal sentence is to start with the participants and the relationship.

First, combine the participants into a plural subject:

::: examples
- no: Mina og Jonas
- en: Mina and Jonas
:::

Then choose the action:

::: examples
- no: Mina og Jonas hjelper
- en: Mina and Jonas help
:::

Finally, add **hverandre**:

::: examples
- no: Mina og Jonas hjelper hverandre.
- en: Mina and Jonas help each other.
:::

If the Norwegian expression needs a preposition, keep it:

::: examples
- no: Sara og Emil snakker med hverandre.
- en: Sara and Emil talk to each other.
:::

Time and place information can make the sentence more useful:

::: examples
- no: Sara og Emil snakker med hverandre etter møtet.
- en: Sara and Emil talk to each other after the meeting.
- no: Vi hjelper hverandre når det er travelt.
- en: We help each other when it is busy.
- no: De ringer hverandre hver fredag.
- en: They call each other every Friday.
:::

The extra information changes the situation, but **hverandre** continues to express the same reciprocal relationship.

## Checkpoint: Combine two directions into one sentence {#checkpoint-combine-directions role=contrast objectives=obj-reciprocal-pronouns-01}

Notice the contrast in Mina’s comment. **Kjenne hverandre** expresses a reciprocal relationship: the volunteers did not know one another. **Le sammen** describes a shared activity: they are laughing together. The sentence uses each expression for its own meaning.

## Guided transfer to a new situation {#guided-transfer-new-situation role=recap objectives=obj-reciprocal-pronouns-01}

Imagine three neighbors in an apartment building. During winter, they clear snow, share equipment, and check that everyone is safe. This setting gives several natural reasons to describe reciprocal actions.

::: examples
- no: Naboene hjelper hverandre med snøen.
- en: The neighbors help one another with the snow.
- no: De låner verktøy av hverandre.
- en: They borrow tools from each other.
- no: De passer på hverandre når det er glatt.
- en: They look after one another when it is slippery.
- no: Før snakket de nesten aldri med hverandre.
- en: Before, they hardly ever talked to each other.
:::

The situation has changed, but the grammar has not. A plural group performs actions that connect its members in two or more directions.

**Request: write-reciprocal-sentences-in-new-context**

**Purpose:** Transfer **hverandre** from the community-center dialogue to a different everyday setting.

**Context:** Use short written prompts about neighbors who exchange help, messages, tools, and information.

**Learner action:** Write complete Norwegian sentences describing the neighbors’ reciprocal actions. Use **hverandre** directly or after the preposition required by the supplied Norwegian verb expression.

**Success meaning:** A successful response independently uses **hverandre** to describe shared actions between two or more people in a new context. The scored evidence goal is controlled production of reciprocal sentences.
