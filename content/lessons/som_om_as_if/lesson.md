## At the office {#at-the-office role=orient objectives=obj-som-om-as-if-01}

Mina and Jonas are having coffee before an announcement about a new department manager. Their colleague Erik seems unusually confident.

::: {.reading translation="Have you seen Erik today?" dialogue_id="office-opening" speaker_id="jonas" speaker_name="Jonas" character_id="jonas"}
Har du sett Erik i dag?
:::

::: {.reading translation="Yes. He is walking around as if he owns the whole office." dialogue_id="office-opening" speaker_id="mina" speaker_name="Mina" character_id="mina"}
Ja. Han går rundt som om han eier hele kontoret.
:::

::: {.reading translation="And he talks as if he is already the department manager." dialogue_id="office-opening" speaker_id="jonas" speaker_name="Jonas" character_id="jonas"}
Og han snakker som om han allerede er avdelingsleder.
:::

::: {.reading translation="Do you know whether he has got the job?" dialogue_id="office-opening" speaker_id="mina" speaker_name="Mina" character_id="mina"}
Vet du om han har fått jobben?
:::

::: {.reading translation="No. If he gets it, we will probably find out this afternoon." dialogue_id="office-opening" speaker_id="jonas" speaker_name="Jonas" character_id="jonas"}
Nei. Hvis han får den, får vi sikkert vite det i ettermiddag.
:::

::: {.reading translation="Right now, he is simply behaving as if everything has been decided." dialogue_id="office-opening" speaker_id="mina" speaker_name="Mina" character_id="mina"}
Akkurat nå oppfører han seg bare som om alt er avgjort.
:::

Mina and Jonas do not know whether Erik has got the job. They are comparing his behaviour with an imagined situation: the situation in which he owns the office, is already the manager, or everything has been decided. Norwegian uses **som om** for this meaning.

## Describing an impression with som om {#describing-an-impression-with-som-om role=model objectives=obj-som-om-as-if-01}

**Som om** normally corresponds to **as if** or **as though**. It introduces an imagined situation that resembles what you can see, hear, or experience.

::: examples
- no: Erik går rundt som om han eier kontoret.
- en: Erik walks around as if he owns the office.
:::

This does not directly claim that Erik owns the office. It describes the impression created by his behaviour.

::: examples
- no: Hun snakker som om hun kjenner alle her.
- en: She speaks as if she knows everyone here.
:::

::: examples
- no: De feirer som om de har vunnet finalen.
- en: They are celebrating as if they have won the final.
:::

::: examples
- no: Du ser ut som om du ikke har sovet.
- en: You look as if you have not slept.
:::

In each case, the first part describes something observable. The clause after **som om** gives the imagined situation that it resembles.

A useful compact rule is:

::: {.rule}
Use **som om** when one action, appearance, sound, or situation creates the impression of another situation.
:::

The comparison does not have to be completely impossible or false. The speaker may simply be unwilling or unable to state it as fact.

::: examples
- no: Det høres ut som om noen banker på døra.
- en: It sounds as if someone is knocking on the door.
:::

Perhaps someone really is knocking. The speaker is reporting how it sounds, not yet presenting the cause as certain.

::: examples
- no: Det ser ut som om bussen er forsinket.
- en: It looks as if the bus is delayed.
:::

The bus may indeed be delayed, but the sentence presents this as a conclusion based on appearances.

## Using som om with a familiar clause pattern {#using-som-om-with-a-familiar-clause-pattern role=model objectives=obj-som-om-as-if-01}

The words following **som om** form a subordinate clause (**leddsetning**), so continue using the familiar subordinate-clause word order required before this lesson.

As a brief reminder, compare a main clause with a clause after **som om**:

::: examples
- no: Han vet ikke svaret.
- en: He does not know the answer.
:::

::: examples
- no: Han snakker som om han ikke vet svaret.
- en: He speaks as if he does not know the answer.
:::

Recall that familiar subordinate-clause order places **ikke** before the finite verb:

::: examples
- no: som om han ikke vet
- en: as if he does not know
:::

The following examples reuse that familiar prerequisite pattern with other sentence adverbs:

::: examples
- no: Hun smiler som om hun aldri blir sliten.
- en: She smiles as if she never gets tired.
:::

::: examples
- no: Han oppfører seg som om han alltid har bodd her.
- en: He behaves as if he has always lived here.
:::

::: examples
- no: De ser på meg som om de kanskje kjenner meg igjen.
- en: They look at me as if they might recognize me.
:::

Keep **som om** together. It functions as the link between the observed situation and the imagined comparison.

::: examples
- no: Katten ligger i sofaen som om den er et menneske.
- en: The cat is lying on the sofa as if it were a person.
:::

::: examples
- no: Nora forklarer reglene som om alle allerede forstår dem.
- en: Nora explains the rules as if everyone already understands them.
:::

## Som om is not the same as om {#som-om-is-not-the-same-as-om role=contrast objectives=obj-som-om-as-if-01}

In English, **if** can appear in several different meanings. This lesson contrasts **som om** for imagined resemblance, **om** for embedded yes-or-no questions, and normally **hvis** for conditions.

**Som om: imagined resemblance**

::: examples
- no: Erik snakker som om han har fått jobben.
- en: Erik talks as if he has got the job.
:::

His way of speaking resembles the behaviour of someone who has got the job.

**Om: an embedded question**

::: examples
- no: Mina spør om Erik har fått jobben.
- en: Mina asks whether Erik has got the job.
:::

Here **om** introduces a yes-or-no question inside a larger sentence. Mina wants information. There is no comparison.

::: examples
- no: Jeg vet ikke om butikken er åpen.
- en: I do not know whether the shop is open.
:::

::: examples
- no: Kan du sjekke om døra er låst?
- en: Can you check whether the door is locked?
:::

These sentences concern uncertainty about a question: Is the shop open? Is the door locked?

Now compare them directly:

::: examples
- no: Hun spør om han er syk.
- en: She asks whether he is ill.
:::

::: examples
- no: Han ser ut som om han er syk.
- en: He looks as if he is ill.
:::

The first sentence reports a question. The second describes an appearance.

## Som om is not a condition {#som-om-is-not-a-condition role=contrast objectives=obj-som-om-as-if-01}

A condition states the circumstance under which another event, result, or possibility applies. Norwegian normally uses **hvis** for this meaning.

::: examples
- no: Hvis Erik får jobben, blir han avdelingsleder.
- en: If Erik gets the job, he will become the department manager.
:::

Getting the job is the condition for becoming manager.

By contrast:

::: examples
- no: Erik oppfører seg som om han allerede er avdelingsleder.
- en: Erik behaves as if he is already the department manager.
:::

This sentence does not set a condition. It compares Erik’s present behaviour with an imagined situation.

Another aligned contrast:

::: examples
- no: Hvis det regner, tar vi bussen.
- en: If it rains, we will take the bus.
:::

::: examples
- no: Det høres ut som om det regner.
- en: It sounds as if it is raining.
:::

The first sentence tells us what will happen on a condition. The second reports an impression based on sound.

And one more:

::: examples
- no: Hvis Sara kjenner sjefen, kan hun spørre ham.
- en: If Sara knows the manager, she can ask him.
:::

::: examples
- no: Sara snakker som om hun kjenner sjefen godt.
- en: Sara talks as if she knows the manager well.
:::

In the conditional sentence, Sara’s knowledge affects what she can do. In the comparison, her manner of speaking creates an impression.

## Common mistakes {#common-mistakes role=contrast objectives=obj-som-om-as-if-01}

**Using om alone for “as if”**

Incorrect for the intended meaning:

::: examples
- no: Han snakker om han vet alt.
- en: Intended meaning: He speaks as if he knows everything.
:::

For imagined resemblance, use the complete expression **som om**:

::: examples
- no: Han snakker som om han vet alt.
- en: He speaks as if he knows everything.
:::

The form with **om** alone does not express the intended comparison.

**Using hvis because English contains “if”**

Incorrect for the intended meaning:

::: examples
- no: Hun ser på meg hvis hun ikke kjenner meg.
- en: 'Not: She looks at me if she does not know me. (for the intended meaning)'
:::

This describes a condition: she looks at me in circumstances where she does not know me. It does not mean that her look creates a particular impression.

For the imagined comparison:

::: examples
- no: Hun ser på meg som om hun ikke kjenner meg.
- en: She looks at me as if she does not know me.
:::

**Treating the comparison as a confirmed fact**

Compare:

::: examples
- no: De har vunnet kampen.
- en: They have won the match.
:::

::: examples
- no: De jubler som om de har vunnet kampen.
- en: They are cheering as if they have won the match.
:::

The first sentence presents the victory as fact. The second describes the impression created by their cheering. They may have won, but the sentence itself does not confirm that.

**Brief reminder inside the complete construction**

Incorrect:

::: examples
- no: Hun snakker som om hun vet ikke hva som skjedde.
- en: Intended meaning: She speaks as if she does not know what happened.
:::

Correct:

::: examples
- no: Hun snakker som om hun ikke vet hva som skjedde.
- en: She speaks as if she does not know what happened.
:::

The familiar prerequisite pattern used here is:

::: examples
- no: som om hun ikke vet
- en: as if she does not know
:::

## Useful situations for som om {#useful-situations-for-som-om role=model objectives=obj-som-om-as-if-01}

Speakers often use **som om** after descriptions of behaviour.

::: examples
- no: Barnet løper rundt som om det har masse energi.
- en: The child is running around as if it has loads of energy.
:::

::: examples
- no: Tobias gir ordre som om han bestemmer her.
- en: Tobias gives orders as if he is in charge here.
:::

::: examples
- no: De hvisker som om møtet allerede har begynt.
- en: They are whispering as if the meeting has already started.
:::

It is also common after expressions describing an appearance, sound, or feeling.

::: examples
- no: Det ser ut som om alle har gått hjem.
- en: It looks as if everyone has gone home.
:::

::: examples
- no: Det høres ut som om naboene har fest.
- en: It sounds as if the neighbours are having a party.
:::

::: examples
- no: Det føles som om vinteren aldri tar slutt.
- en: It feels as if winter never ends.
:::

The same construction can express a speaker’s critical or humorous attitude.

::: examples
- no: Han klager som om dette er verdens største problem.
- en: He complains as if this were the biggest problem in the world.
:::

::: examples
- no: Du pakker som om vi skal være borte i en måned.
- en: You are packing as if we are going to be away for a month.
:::

::: examples
- no: Hun beskytter den gamle koppen som om den er svært verdifull.
- en: She protects the old cup as if it were extremely valuable.
:::

The tone comes from the comparison and the context. **Som om** itself does not automatically mean that the speaker is mocking someone.

## Checkpoint request: build-comparison-from-observation {#checkpoint-build-comparison-from-observation role=contrast objectives=obj-som-om-as-if-01}

The learner should receive brief paired descriptions: one observable action or impression and one imagined explanation. The learner should combine each pair into a single natural sentence with **som om**. Contexts should include behaviour, appearance, and sound, while avoiding unrelated new grammar.

This controlled production activity belongs after several model patterns. Its primary scored evidence is whether the learner can connect a real observation to an imagined comparison with **som om**. Success demonstrates form–meaning control rather than simple connector selection.

## Back at the office {#back-at-the-office role=orient objectives=obj-som-om-as-if-01}

Later that afternoon, Mina and Jonas receive the announcement.

::: {.reading translation="Now we know whether Erik got the job." dialogue_id="office-follow-up" speaker_id="mina" speaker_name="Mina" character_id="mina"}
Nå vet vi om Erik fikk jobben.
:::

::: {.reading translation="Yes, and he did not." dialogue_id="office-follow-up" speaker_id="jonas" speaker_name="Jonas" character_id="jonas"}
Ja, og det gjorde han ikke.
:::

::: {.reading translation="Even so, he is smiling as if nothing has happened." dialogue_id="office-follow-up" speaker_id="mina" speaker_name="Mina" character_id="mina"}
Likevel smiler han som om ingenting har skjedd.
:::

::: {.reading translation="Perhaps he is only trying to appear calm." dialogue_id="office-follow-up" speaker_id="jonas" speaker_name="Jonas" character_id="jonas"}
Kanskje han bare prøver å virke rolig.
:::

The new information changes what Mina and Jonas know, but it does not change the function of **som om**. Mina observes Erik’s smile and compares it with the behaviour of someone unaffected by the announcement.

Notice the contrast between information and impression:

::: examples
- no: Nå vet vi om Erik fikk jobben.
- en: Now we know whether Erik got the job.
:::

::: examples
- no: Erik smiler som om ingenting har skjedd.
- en: Erik smiles as if nothing has happened.
:::

The first sentence concerns the answer to a question. The second interprets observable behaviour through an imagined comparison.

## Checkpoint request: interpret-office-follow-up {#checkpoint-interpret-office-follow-up role=contrast objectives=obj-som-om-as-if-01}

The learner should explain the difference between the two uses surrounding Erik’s result: knowing **om** something happened and smiling **som om** nothing happened. The learner should then write one additional sentence describing Erik’s behaviour through an imagined comparison.

This activity returns to the anchor after the explanation. Its primary scored evidence is appropriate use of **som om** to interpret behaviour. Success demonstrates that the learner can apply the construction when the surrounding story includes both factual information and uncertainty language.

## Cumulative transfer: a delayed train {#cumulative-transfer-a-delayed-train role=recap objectives=obj-som-om-as-if-01}

Imagine a new scene at a railway station. The departure board has stopped updating. One traveller repeatedly checks the time, another is unpacking food for a long wait, and a railway employee continues working calmly. The travellers do not yet know whether the train has been cancelled.

**Request: transfer-som-om-station-scene**

The learner should write a short, controlled description of the station scene using several prompted observations. Each response should compare visible behaviour with an imagined situation by using **som om**. The prompts should supply natural subordinate clauses using only familiar prerequisite language.

This transfer belongs at the end because it removes the office wording while preserving the same communicative purpose. Its primary scored evidence is independent written use of **som om** for imagined resemblance. The condition and embedded-question patterns may appear in the scene description as context, but they are not additional production goals.
