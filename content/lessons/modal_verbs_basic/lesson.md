## A Saturday plan {#sec-a-saturday-plan role=orient objectives=obj-modal-verbs-basic-01}

It is Saturday morning. Nora and Amir share a flat in Oslo. They are deciding what to do before Nora’s sister visits in the afternoon.

::: {.reading translation="What are you going to do today?" dialogue_id="saturday-plan" speaker_id="nora" speaker_name="Nora" character_id="nora"}
Hva skal du gjøre i dag?
:::

::: {.reading translation="I’m going to buy food." dialogue_id="saturday-plan" speaker_id="amir" speaker_name="Amir" character_id="amir"}
Jeg skal kjøpe mat.
:::

::: {.reading translation="Can you buy coffee too?" dialogue_id="saturday-plan" speaker_id="nora" speaker_name="Nora" character_id="nora"}
Kan du kjøpe kaffe også?
:::

::: {.reading translation="Yes, but I have to leave now. The shop closes early." dialogue_id="saturday-plan" speaker_id="amir" speaker_name="Amir" character_id="amir"}
Ja, men jeg må gå nå. Butikken stenger tidlig.
:::

::: {.reading translation="Wait a moment. I want to make soup, so we have to buy vegetables." dialogue_id="saturday-plan" speaker_id="nora" speaker_name="Nora" character_id="nora"}
Vent litt. Jeg vil lage suppe, så vi må kjøpe grønnsaker.
:::

::: {.reading translation="All right. Shall we eat at home this evening?" dialogue_id="saturday-plan" speaker_id="amir" speaker_name="Amir" character_id="amir"}
Greit. Skal vi spise hjemme i kveld?
:::

::: {.reading translation="Yes. My sister can come at six." dialogue_id="saturday-plan" speaker_id="nora" speaker_name="Nora" character_id="nora"}
Ja. Søsteren min kan komme klokka seks.
:::

::: {.reading translation="Then I’ll buy some extra food." dialogue_id="saturday-plan" speaker_id="amir" speaker_name="Amir" character_id="amir"}
Da skal jeg kjøpe litt ekstra mat.
:::

The conversation contains four very useful verbs: *kan, vil, må,* and *skal*. Nora and Amir use them to talk about ability or possibility, wishes, necessity, and plans. Each one is followed by another verb:

::: examples
- no: kan kjøpe
- en: can buy
- no: må gå
- en: must leave
- no: vil lage
- en: wants to make
- no: skal spise
- en: is going to eat
:::

Notice something important: the second verb does not have *å* before it.

## One sentence pattern, four meaning choices {#sec-one-sentence-pattern-four-meaning-choices role=model objectives=obj-modal-verbs-basic-01}

You already know that Norwegian often uses the infinitive marker *å* before an infinitive:

::: examples
- no: Jeg liker å lage mat.
- en: I like to cook.
:::

After *kan, vil, må,* and *skal*, however, the infinitive marker disappears. The second verb is a **bare infinitive**, meaning an infinitive without *å*.

::: examples
- no: Jeg kan lage mat.
- en: I can cook.
- no: Jeg vil lage mat.
- en: I want to cook.
- no: Jeg må lage mat.
- en: I have to cook.
- no: Jeg skal lage mat.
- en: I am going to cook.
:::

::: {.rule}
The sentence structure is compact: **subject + kan/vil/må/skal + bare infinitive**
:::

The form of the modal verb does not change with the subject:

::: examples
- no: Jeg kan svømme.
- en: I can swim.
- no: Du kan svømme.
- en: You can swim.
- no: Hun kan svømme.
- en: She can swim.
- no: Vi kan svømme.
- en: We can swim.
:::

The main decision is therefore not which ending to use. It is which meaning you want: ability or possibility, desire, necessity, or a plan.

## *Kan*: ability and possibility {#sec-kan-ability-and-possibility role=model objectives=obj-modal-verbs-basic-01}

Use *kan* when someone is able to do something or when something is possible.

**Ability**

::: examples
- no: Amir kan lage suppe.
- en: Amir can make soup.
- no: Jeg kan snakke litt norsk.
- en: I can speak a little Norwegian.
- no: Hun kan kjøre bil.
- en: She can drive.
- no: Vi kan hjelpe deg.
- en: We can help you.
:::

In these examples, *kan* describes what a person is able to do.

**Possibility**

In the dialogue, Nora says:

::: examples
- no: Søsteren min kan komme klokka seks.
- en: My sister can come at six.
:::

Here, *kan* presents six o’clock as possible. Compare:

::: examples
- no: Hun kan komme i dag.
- en: She can come today.
- no: Hun skal komme i dag.
- en: She is going to come today.
:::

The first sentence says that coming today is possible. The second presents it as her plan.

A common mistake is to add *å*:

**Incorrect:**

::: examples
- no: ✗ Jeg kan å svømme.
- en: I can swim.
:::

**Correct:**

::: examples
- no: Jeg kan svømme.
- en: I can swim.
:::

::: {.rule}
Compact rule: after *kan*, use the bare infinitive.
:::

## *Vil*: what someone wants to do {#sec-vil-what-someone-wants-to-do role=model objectives=obj-modal-verbs-basic-01}

Use *vil* before a bare infinitive to say what someone wants to do.

Nora says:

::: examples
- no: Jeg vil lage suppe.
- en: I want to make soup.
:::

More examples:

::: examples
- no: Jeg vil spise nå.
- en: I want to eat now.
- no: Oskar vil lære norsk.
- en: Oskar wants to learn Norwegian.
- no: Barna vil leke ute.
- en: The children want to play outside.
- no: Vi vil se filmen.
- en: We want to see the film.
:::

In English, *will* often marks the future. Norwegian *vil* can have future uses too, but in the simple personal sentences in this lesson, read it primarily as **want to**. If Liv says:

::: examples
- no: Jeg vil kjøpe en sykkel.
- en: I want to buy a bicycle.
:::

she is expressing a wish. She is not necessarily reporting a settled plan.

Compare *vil* with *skal*:

::: examples
- no: Jeg vil besøke Bergen.
- en: I want to visit Bergen.
- no: Jeg skal besøke Bergen på fredag.
- en: I am going to visit Bergen on Friday.
:::

The first sentence expresses desire. The second presents a plan.

Again, do not use *å* after the modal:

**Incorrect:**

::: examples
- no: ✗ Vi vil å spise hjemme.
- en: We want to eat at home.
:::

**Correct:**

::: examples
- no: Vi vil spise hjemme.
- en: We want to eat at home.
:::

## *Må*: necessity {#sec-ma-necessity role=model objectives=obj-modal-verbs-basic-01}

Use *må* when something is necessary: someone must do it or has to do it.

Amir says:

::: examples
- no: Jeg må gå nå.
- en: I have to leave now.
:::

Nora later adds:

::: examples
- no: Vi må kjøpe grønnsaker.
- en: We have to buy vegetables.
:::

More examples:

::: examples
- no: Du må vente litt.
- en: You have to wait a little.
- no: Sara må jobbe i kveld.
- en: Sara has to work this evening.
- no: Jeg må ringe legen.
- en: I have to call the doctor.
- no: Vi må ta bussen.
- en: We have to take the bus.
:::

Compare desire and necessity:

::: examples
- no: Jeg vil gå hjem.
- en: I want to go home.
- no: Jeg må gå hjem.
- en: I have to go home.
:::

The action is the same, but the reason is different. *Vil* comes from what the speaker wants. *Må* presents the action as necessary.

A learner may be tempted to translate English “to” directly:

**Incorrect:**

::: examples
- no: ✗ Sara må å jobbe.
- en: Sara has to work.
:::

**Correct:**

::: examples
- no: Sara må jobbe.
- en: Sara has to work.
:::

::: {.rule}
Compact rule: *må* is followed directly by the bare infinitive.
:::

## *Skal*: plans and intended actions {#sec-skal-plans-and-intended-actions role=model objectives=obj-modal-verbs-basic-01}

Use *skal* with a bare infinitive to present an intended or arranged action. English often uses “am/is/are going to” in the translation.

At the beginning of the dialogue, Amir says:

::: examples
- no: Jeg skal kjøpe mat.
- en: I’m going to buy food.
:::

He has a plan. Later he adjusts it:

::: examples
- no: Jeg skal kjøpe litt ekstra mat.
- en: I’ll buy some extra food.
:::

More examples:

::: examples
- no: Jeg skal møte Eva klokka tre.
- en: I’m going to meet Eva at three.
- no: De skal reise til Trondheim i morgen.
- en: They are going to travel to Trondheim tomorrow.
- no: Vi skal spise hjemme i kveld.
- en: We are going to eat at home this evening.
- no: Mina skal jobbe på lørdag.
- en: Mina is going to work on Saturday.
:::

Compare the four modal verbs with the same main verb:

::: examples
- no: Jeg kan lage middag.
- en: I can make dinner.
- no: Jeg vil lage middag.
- en: I want to make dinner.
- no: Jeg må lage middag.
- en: I have to make dinner.
- no: Jeg skal lage middag.
- en: I am going to make dinner.
:::

These sentences do not describe four different actions. They show four different ways of viewing the same action:

- *kan* presents ability or possibility;
- *vil* presents desire;
- *må* presents necessity;
- *skal* presents a plan or intended action.

Do not add *å* after *skal*:

**Incorrect:**

::: examples
- no: ✗ De skal å reise i morgen.
- en: They are going to travel tomorrow.
:::

**Correct:**

::: examples
- no: De skal reise i morgen.
- en: They are going to travel tomorrow.
:::

## The choice changes the message {#sec-choice-changes-the-message role=contrast objectives=obj-modal-verbs-basic-01}

The shared grammar pattern is easy to see, but choosing the correct modal requires attention to the situation.

Imagine that Jonas is talking about a concert:

::: examples
- no: Jonas kan gå på konserten.
- en: Jonas can go to the concert.
- no: Jonas vil gå på konserten.
- en: Jonas wants to go to the concert.
- no: Jonas må gå på konserten.
- en: Jonas has to go to the concert.
- no: Jonas skal gå på konserten.
- en: Jonas is going to go to the concert.
:::

He is able to go, or going is possible.

Going is his wish.

Going is necessary.

Going is his plan.

The bare infinitive *gå* stays the same. The modal verb changes the meaning.

Here is another aligned contrast:

::: examples
- no: Vi kan ta toget.
- en: We can take the train.
- no: Vi vil ta toget.
- en: We want to take the train.
- no: Vi må ta toget.
- en: We have to take the train.
- no: Vi skal ta toget.
- en: We are going to take the train.
:::

When you build such sentences, make two decisions:

1. What meaning is intended?
2. Which bare infinitive names the action?

Then put them together without *å*.

## Returning to Nora and Amir {#sec-returning-to-nora-and-amir role=contrast objectives=obj-modal-verbs-basic-01}

Amir is now ready to leave. Nora checks the plan one more time.

::: {.reading translation="Can you carry two bags?" dialogue_id="saturday-plan-return" speaker_id="nora" speaker_name="Nora" character_id="nora"}
Kan du bære to poser?
:::

::: {.reading translation="Yes, I can. What do you want to eat for dessert?" dialogue_id="saturday-plan-return" speaker_id="amir" speaker_name="Amir" character_id="amir"}
Ja, det kan jeg. Hva vil du spise til dessert?
:::

::: {.reading translation="I want to make apple cake, but I have to buy apples." dialogue_id="saturday-plan-return" speaker_id="nora" speaker_name="Nora" character_id="nora"}
Jeg vil lage eplekake, men jeg må kjøpe epler.
:::

::: {.reading translation="All right. I’ll buy apples too." dialogue_id="saturday-plan-return" speaker_id="amir" speaker_name="Amir" character_id="amir"}
Greit. Jeg skal kjøpe epler også.
:::

::: {.reading translation="Great. Then we can eat apple cake this evening." dialogue_id="saturday-plan-return" speaker_id="nora" speaker_name="Nora" character_id="nora"}
Flott. Da kan vi spise eplekake i kveld.
:::

The four choices now have clear jobs in the scene:

- Nora asks about Amir’s ability with *kan bære*.
- She expresses a wish with *vil lage*.
- She states a necessity with *må kjøpe*.
- Amir states his intention with *skal kjøpe*.
- Nora presents a future possibility with *kan spise*.

All five combinations use a bare infinitive.

## Common mistakes to avoid {#sec-common-mistakes-to-avoid role=contrast objectives=obj-modal-verbs-basic-01}

**Adding *å***

The most important form mistake is placing *å* between the modal and the action verb.

**Incorrect:**

::: examples
- no: ✗ Jeg vil å lære norsk.
- en: I want to learn Norwegian.
:::

**Correct:**

::: examples
- no: Jeg vil lære norsk.
- en: I want to learn Norwegian.
:::

**Incorrect:**

::: examples
- no: ✗ Vi må å vente.
- en: We have to wait.
:::

**Correct:**

::: examples
- no: Vi må vente.
- en: We have to wait.
:::

Use *å* in a sentence such as:

::: examples
- no: Jeg liker å lære norsk.
- en: I like learning Norwegian.
:::

But after *kan, vil, må,* and *skal*, use the infinitive directly:

::: examples
- no: Jeg kan lære norsk.
- en: I can learn Norwegian.
:::

**Changing the modal for the subject**

Do not add a special ending because the subject changes.

::: examples
- no: Jeg skal jobbe.
- en: I am going to work.
- no: Hun skal jobbe.
- en: She is going to work.
- no: De skal jobbe.
- en: They are going to work.
:::

The same is true of *kan, vil,* and *må*.

**Choosing by action rather than meaning**

No action verb automatically belongs with one modal. *Spise* can follow all four:

::: examples
- no: Jeg kan spise nå.
- en: I can eat now.
- no: Jeg vil spise nå.
- en: I want to eat now.
- no: Jeg må spise nå.
- en: I have to eat now.
- no: Jeg skal spise nå.
- en: I am going to eat now.
:::

Choose the modal from the intended meaning, not from the action itself.
